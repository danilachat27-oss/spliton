# Партнёрская программа — гид пользователя

## Для кого

Аффилиаты, инфлюенсеры, агентства, менеджеры артистов — расширенные условия и отдельный код после одобления.

## Как подать заявку

1. [Партнёрская программа](/partner-program) → блок «Партнёрский кабинет».
2. Выберите тип, опишите аудиторию и каналы.
3. Дождитесь статуса **Одобрен**.

## После одобрения

- Персональная партнёрская ссылка (код `P-…`).
- Дашборд: приглашения, выплаченные комиссии.
- Комиссия по tier / индивидуальному проценту (secondary fees).

## Выплаты

Начисления проходят через ту же систему, что и реферальные награды — зачисление на баланс USDT в Spliton после одобрения.

## Статусы

Заявка отправлена → на рассмотрении → одобрен / отклонён / приостановлен.

Контакт для вопросов — через поддержку в кабинете (не только email).
