# Реферальная программа — гид пользователя

## Как получить ссылку

1. Войдите в Spliton.
2. Откройте [Реферальная программа](/referral-program).
3. Скопируйте ссылку или код.

## Как пригласить

- Отправьте ссылку другу — регистрация с `?ref=КОД`.
- Или назовите код при регистрации.

Если забыли код при регистрации — блок «У меня есть реферальный код» на странице программы (один раз).

## Награды

Зависят от правил платформы (email, первое пополнение, покупка units, комиссии вторичного рынка). Статусы:

- **В ожидании** — проверка / квалификация
- **Доступно** — одобрено, зачисление на баланс
- **Выплачено** — USDT на кошельке Spliton

## Выписка

Кнопки CSV / JSON на вкладке «Программа» → блок «Приглашённые».

## Ограничения

- Нельзя пригласить самого себя.
- Один реферер на аккаунт.
- Мошенничество и мультиаккаунты — отказ в выплате.

Поддержка: раздел «Поддержка» в кабинете.
