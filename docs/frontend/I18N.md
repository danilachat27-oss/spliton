# Spliton I18N

## Языки

- `ru` — основной, fallback по умолчанию
- `en` — English
- `es` — Español
- `pt` — Português

## Где лежат переводы

- `apps/frontend/lib/i18n/types.ts` — типы и метаданные языков
- `apps/frontend/lib/i18n/dictionaries.ts` — merge словарей (common, shell, disputes, …)
- `apps/frontend/lib/i18n/disputes-messages.ts` — центр споров
- `apps/frontend/lib/i18n/locale-storage.ts` — cookie/localStorage `spliton_locale`
- `apps/frontend/components/providers/i18n-provider.tsx` — `I18nProvider`, `useI18n()`
- Admin RU-источник: `apps/frontend/features/admin/lib/admin-i18n.ts` (постепенная миграция)

## Как добавить ключ

1. Добавьте строку во все три секции в `dictionaries.ts` (или доменный файл, если выделите позже).
2. Используйте `const { t } = useI18n(); t("your.key")`.
3. В dev missing key логируется в console.

## Fallback

1. Текущая локаль
2. `ru`
3. Переданный `fallback` аргумент
4. Сам ключ (dev warning)

## Language selector

Компонент: `apps/frontend/components/i18n/language-selector.tsx`

- Dashboard header (variant `dark`) — флаги 🇷🇺 🇬🇧 🇬🇪
- Admin header (variant `admin`)
- Profile settings — `LanguageSelector` + sync с `I18nProvider`
- Сохранение: localStorage + cookie `spliton_locale`; для авторизованных — `PATCH /users/me/preferences`

## System announcements (i18n)

- Баннеры: `components/system-announcements/system-announcement-banners.tsx`
- API отдаёт `title`/`message` по `?locale=`
- Admin create: вкладки RU/EN/KA в `/admin/system-status`

## Error formatting

- `lib/i18n/format-api-error.ts` — единый mapper для UI
- `hooks/use-api-error-message.ts` — в React-компонентах
